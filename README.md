# berceste.app

Berceste uygulamasının tanıtım sitesi. Düz HTML, build adımı yok; GitHub Pages `main` dalının kökünden yayınlar.

- `app-ads.txt` — AdMob yayıncı doğrulaması
- `gizlilik-politikasi.html`, `kullanim-sartlari.html`, `hesap-silme.html` — mağaza ve uygulama içi linkler (`/gizlilik-politikasi` gibi uzantısız adresler GitHub Pages tarafından otomatik çözülür)
- `CNAME` — özel alan adı
